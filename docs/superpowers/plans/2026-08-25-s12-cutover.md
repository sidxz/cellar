## Steps

- [ ] **Step 1 — Preconditions.** `intranet-db` up (`docker ps`); dev backend running from the current branch (it auto-reloads) and `alembic current` = `068_plate_comments` (`make migrate` if not); the S11 fix wave (C1 timezone, I1 name recovery, I3 `unmapped_users.csv`, I4 backfill gate) merged into the branch; `caffeinate -i` running (the Mac sleeps after 1 min).

- [ ] **Step 2 — Pre-check the workspace** (read-only SQL via `uv run python` + SQLAlchemy, `DATABASE_URL` from `.env`):
  - `registered_plates WHERE workspace_id=:ws AND owner_org_id IS NULL` → count + barcodes (decides `--backfill-null-owners`).
  - `plate_loans WHERE workspace_id=:ws AND (notes LIKE 'Migrated from legacy%' OR notes LIKE 'Legacy transaction%')` → expect 0 (an earlier partial run would block comment import for those loans — delete or accept).
  - active `plate_loan_items` on any legacy barcode → expect 0.
  - `cdd_plate_sync` rows + the DataSource vault id → confirm `--cdd-vault-id`.
  - `controlled_vocabularies` named `plate_group_type` / `plate_group_state` → present or absent, both fine.
  - Existing `plate_groups` in the workspace (dry-run #1 saw 8 pre-existing: SAC1/SAC2/Sanofi seeds from S3/S5 verification) → they will be **reused by name**; decide whether to delete the seed groups first so counts match the legacy tree exactly (101 created) — user's call.

- [ ] **Step 3 — Dry-run #2** with the final inputs (`--dry-run`). Expected counters: `locations_created 15`, `plates_matched 2259` (`plates_created ≈ 2247`, `cdd_sync_rows 639`), `unmatched_plates 0`, `status_conflicts 0`, `groups_created 93–101`, `plates_grouped 2248`, `loans_created 8`, `closed_loans_created 752`, `closed_lines_unparsed 0`, `comments_created ≈ 1303`, `unmapped_users` = 39 minus the map. Review every CSV in the report dir with the user: `created_plates.csv` (spot-check 5 barcodes against the legacy UI), `unmapped_users.csv`, `unresolved_requesters.csv`, `closed_loans_unparsed.csv` (expect empty), `status_conflicts.csv` (expect empty), `owner_backfilled.csv` (only if the flag is on).

- [ ] **Step 4 — Backup.** `pg_dump` of the dev database (or at least the tables `registered_plates, plate_groups, plate_loans, plate_loan_items, plate_comments, storage_locations, cdd_plate_sync, tags, plate_tag_links, controlled_vocabularies`) to the scratchpad before the real run — the run is one transaction, but a wrong input (vault id, building name) is only undone by restoring.

- [ ] **Step 5 — GATE: ask the user to confirm the real run** (inputs table + dry-run #2 counters + the backup path). Proceed only on an explicit yes.

- [ ] **Step 6 — Real run** (same command without `--dry-run`). Save the log + reports. Expect the same counters.

- [ ] **Step 7 — Spot-check in the UI** (user signed in as admin): SAC1 tree with state colors + metadata cards; a `legacy:inactive` plate at `depleted`; an override-closed loan (items `returned`, no scan-back line) and a denied-only loan (legacy txn 875) in Loans → All; a group's comments and a plate's comments with historical timestamps rendered in local time (an afternoon comment shows as afternoon — the C1 check); the 8 open loans in Approvals/My requests with correct statuses; a kiosk scan on a dev device against one of the migrated `approved` items (then cancel it).

- [ ] **Step 8 — Idempotency proof.** Re-run with `--dry-run`: every `*_created` counter is 0 and `plates_matched 2259`.

- [ ] **Step 9 — Docs + tracking.** Spec "S12 sync note" (final counters, inputs used, decisions on backfill/seed groups/user-map), `docs/backlog/s6-legacy-migration-deferred-minors.md` close-out, issue #71 comment, memory update (legacy DB can be stopped: `docker compose stop intranet-db`).
