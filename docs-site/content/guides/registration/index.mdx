# Registration guides

**What you'll find here:** Step-by-step instructions for every task in chemcellar's chemical registration workflow — from drawing a single structure to importing hundreds of compounds from a file.

[Chemical registration](/reference/glossary#chemical-registration) is the process of recording a compound's identity in chemcellar so that it can participate in experiments, inventory tracking, and data analysis. Before any compound can be plated in an assay, sampled from a vial, or analyzed for structure-activity relationships, it must be registered.

## What registration does

When you register a molecule, chemcellar:

1. Normalizes the structure (strips salts, computes a canonical SMILES, generates an [InChIKey](/reference/glossary#inchikey)) using RDKit and the ChEMBL structure pipeline.
2. Checks the workspace for an existing molecule with the same InChIKey. If one is found, a new [batch](/reference/glossary#batch) is added to the existing molecule rather than creating a duplicate.
3. Assigns a permanent [registration number](/reference/glossary#registration-number) (e.g., `CV-00001`) that never changes, even if the molecule is later merged with another record.
4. Computes physicochemical descriptors (molecular weight, logP, TPSA, hydrogen-bond donors and acceptors) and stores them alongside the structure.

<Callout type="info">
chemcellar canonicalizes every disclosed structure on registration. Two different SMILES strings that describe the same molecule will always produce the same InChIKey and will be recognized as the same compound.
</Callout>
