# Screening guides

**What you'll find here:** Step-by-step instructions for every task in chemcellar's screening and assay workflow — from defining a reusable protocol to approving a completed run and locking its data.

Screening in chemcellar is the structured process of running biological experiments against registered compounds, capturing the resulting measurements, and curating that data for downstream analysis. Every measured value is traceable back to the exact protocol, physical plate, and compound batch that produced it.

## How screening is organized

A complete screening experiment in chemcellar has four nested levels:

| Level | What it represents |
|-------|--------------------|
| **[Protocol](/reference/glossary#protocol)** | A reusable, versioned description of an assay — what it measures, against which target, and how results are normalized |
| **[Run](/reference/glossary#run)** | One execution of a protocol on a specific date |
| **[Plate](/reference/glossary#plate)** | A physical microplate used in that run |
| **[Well](/reference/glossary#well)** | A single position on a plate, holding one compound batch at one concentration |

[Readout data](/reference/glossary#readout-data) records the measured result for each well. For concentration-response experiments, [dose-response curves](/concepts/dose-response) are fitted automatically from that data.
